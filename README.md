# This SQL Analysis Project Consist of Different types of quesitons where you can learn beginner to advance SQL Querries in the form of Questions.

There are Questions from Beginner to Advanced Level, Every File of SQL Consists of Question, Question Level and Solution in SQL Queries.  
Question 1 - (Beginner) -> Retrieve the total number of orders placed.  
Question 2 - (Beginner) -> Calculate the total revenue generated from pizza sales.  
Question 3 - (Beginner) -> Identify the highest priced pizza.  
Question 4 - (Beginner) -> Identify the most common pizza size orders.  
Question 5 - (Beginner) -> List the top 5 most ordered pizza types along with their quantities.   
  
Question 1 - (Intermediate) -> Join the necessary tables to find the total quantity of each pizza category ordered.  
Question 2 - (Intermediate) -> Determine the distribution of orders by hour of the day.  
Question 3 - (Intermediate) -> Join relevant tables to find the category wise distribution of pizzas.   
Question 4 - (Intermediate) -> Group the orders by date and calculate the average number of pizzas ordered per day.  
Question 5 - (Intermediate) -> Determine the top 3 most ordered pizza types based on revenue.  
  
Question 1 - (Advanced) -> Calculate the percentage contribution of each pizza type to total revenue.  
Question 2 - (Advanced) -> Analyze the cumulative revenue generated over time.  
Question 3 - (Advanced) -> Determine the top 3 most ordered pizza types based on revenue for each pizza category.
